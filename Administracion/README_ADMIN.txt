   https://TU-USUARIO.github.io/TU-REPOSITORIO/admin.html

IMPORTANTE — VERSIÓN ACTUAL
Este panel es una versión funcional de administración LOCAL:
- Agrega imágenes.
- Edita títulos y descripciones.
- Elimina obras.
- Edita los textos de los estilos.
- Guarda los datos en el navegador mediante localStorage.
- Permite exportar e importar una copia JSON.

Esto significa que los cambios realizados aquí se guardan en TU navegador.
No se envían automáticamente a todos los visitantes del sitio.

SIGUIENTE ETAPA RECOMENDADA
Para que los cambios que hagas como administrador aparezcan automáticamente para TODOS los visitantes, debemos conectar este panel a una base de datos y almacenamiento de imágenes (por ejemplo Supabase).

Cuando conectemos Supabase:
- Tú iniciarás sesión.
- Subirás imágenes.
- Los textos se guardarán online.
- La página pública NOIR leerá esos datos automáticamente.
- Los visitantes verán tus cambios sin que tú entres al código ni a GitHub.

Esta versión sirve para aprobar el diseño y la experiencia del panel de administración antes de conectar la base de datos.
