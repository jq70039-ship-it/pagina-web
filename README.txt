NOIR — TATTOO STUDIO
VERSIÓN: Imágenes + Galerías por estilo

CAMBIOS PRINCIPALES
-------------------
1. Se reemplazaron las imágenes genéricas por fotografías relacionadas con tatuajes.
2. Se agregaron 4 estilos:
   - Blackwork
   - Fine Line
   - Ornamental
   - Neo Modern / Body Flow
3. Cada botón "EXPLORAR..." baja directamente a su galería.
4. Cada galería contiene 10 imágenes.
5. Las galerías tienen:
   - desplazamiento horizontal
   - efecto hover con zoom
   - aparición al hacer scroll
   - apertura de imagen en pantalla completa
6. La galería general también abre las imágenes en pantalla completa.

IMPORTANTE SOBRE LAS IMÁGENES
-----------------------------
La referencia visual se investigó con inspiración de Pinterest y portafolios
de tatuajes, pero para el sitio se utilizaron URLs de fotografías de Pexels
relacionadas directamente con tatuajes. Esto evita depender de hotlinks de
Pinterest, que pueden romperse o estar sujetos a derechos/licencias no aptas
para reutilización directa.

CÓMO SUBIR A GITHUB
-------------------
1. Descomprime este archivo ZIP.
2. Entra a la carpeta NOIR_Tattoo_Studio_Imagenes_y_Galerias.
3. Sube o reemplaza:
   - index.html
   - style.css
   - script.js
4. GitHub Pages actualizará el sitio automáticamente.

NOTA
----
Las imágenes se cargan desde Pexels mediante URL externa, por lo que no
aumentan el tamaño del repositorio. Si después quieres tener las imágenes
guardadas dentro de tu propio repositorio, se pueden descargar versiones
con licencia adecuada y colocarlas en una carpeta /images.
