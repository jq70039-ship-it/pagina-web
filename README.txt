INICIO RÁPIDO — NOIR TATTOO STUDIO

1. Instala Visual Studio Code.
2. Descomprime esta carpeta.
3. Abre la carpeta completa desde Visual Studio Code.
4. Instala la extensión Live Server.
5. Haz clic derecho sobre index.html.
6. Selecciona Open with Live Server.

ARCHIVOS:
- index.html = estructura y textos.
- style.css = diseño, colores, tamaños y distribución.
- script.js = comportamiento.
- images/ = aquí colocarás las fotografías.

PARA CAMBIAR UNA IMAGEN:
1. Copia la imagen dentro de images/.
2. Renómbrala exactamente como indica el CSS.
   Ejemplo: blackwork-1.jpg
3. Guarda los cambios.
4. El navegador se actualizará.
